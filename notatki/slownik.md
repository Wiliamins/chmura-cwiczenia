# Słownik odpowiedników usług chmurowych

| Rodzaj usługi | AWS | Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne | EC2 | Virtual Machines | Compute Engine |
| Magazyn obiektów | S3 | Blob Storage | Cloud Storage |
| Funkcje bezserwerowe (FaaS) | Lambda | Azure Functions | Cloud Run functions |
| Platforma aplikacji (PaaS) | Elastic Beanstalk | App Service | App Engine |
| Zarządzana relacyjna baza danych | RDS | Azure SQL Database | Cloud SQL |
| Zarządzany Kubernetes | EKS | AKS | GKE |
